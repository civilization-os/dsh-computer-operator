# 桌面计算机视觉与键鼠自动化技能

当需要操作 Windows 操作系统、桌面应用程序（如 Chrome、Edge、Office、各类客户端、文件管理器等）时，使用本技能提供的桌面级工具。

## 核心操作规范

1. **指定对应窗口捕获（强烈推荐）**：
   - 当需要操作特定应用（例如已打开的 Chrome、记事本或后台程序）时，在 `desktop_screenshot` 中传入 `targetTitle: "窗口标题关键字或进程名"`（如 `"Web form"`、`"Google Chrome"`、`"Chrome"`、`"notepad"`）。
   - **穿透遮挡**：即使目标窗口被其他全屏游戏或最大化软件压在最下层，也能通过底层穿透 100% 捕获该窗口内部的真实画面（包括所有输入框、按钮）。
   - **1:1 原生分辨率**：窗口截图默认保持 1:1 真实物理分辨率，绝不强制降采样，彻底杜绝坐标缩放算错的问题。
   - **窗口内相对坐标**：在此截图上观察到的坐标直接即为该窗口的相对坐标 $(x, y)$。后续调用 `desktop_mouse_click` 时带上同样的 `targetTitle`，系统会自动将消息直接送达该窗口对应的像素点。

2. **全屏桌面观察**：
   - 省略 `targetTitle` 时将截取整个桌面。
   - 可通过 `scaleDown: "none"` 获取 4K 原生原图（便于高精细节与无误差裁切），或 `scaleDown: "1080p"`（节省 Token 并带有 1:1 锐利刻度网格）。

3. **双模静默模式（默认启用）**：
   - **浏览器网页操作 (CDP 内核直通)**：当 Chrome/Edge 开启了远程调试端口（`--remote-debugging-port=9222`）时，插件底层自动走 CDP 协议直通浏览器内核。物理光标 0 移位、前台焦点 0 抢夺，直接在 DOM 树中完成点击与填表。
   - **桌面应用操作 (Win32 原生通道)**：对于记事本、系统设置、日常客户端，底层通过 Win32 消息队列直接向窗口句柄投递输入。
   - **特点**：物理鼠标光标留在原地不动，用户正在前台打字的活跃窗口焦点绝不被抢走。

4. **标准闭环流程**：
   - **步骤 1（窗口观察）**：`desktop_screenshot({ targetTitle: "目标窗口名称" })`，获取清晰的对应窗口内容。
   - **步骤 2（精准定位）**：在获得的窗口画面中定位目标组件坐标 $(x, y)$。
   - **步骤 3（静默交互）**：`desktop_mouse_click({ x, y, targetTitle: "目标窗口名称" })`。
   - **步骤 4（键入确认）**：`desktop_keyboard_type({ text: "内容", targetTitle: "目标窗口名称" })`。
